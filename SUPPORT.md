# Support

- **Documentation**: <https://stevenayers.github.io/pytest-databricks-lakeflow/>. Start with [Getting started](https://stevenayers.github.io/pytest-databricks-lakeflow/getting-started/) and the [Limitations and FAQ](https://stevenayers.github.io/pytest-databricks-lakeflow/limitations/).
- **Questions**: open an issue with the [Question](https://github.com/stevenayers/pytest-databricks-lakeflow/issues/new?template=question.yml) form.
- **Bugs**: open an issue with the [Bug report](https://github.com/stevenayers/pytest-databricks-lakeflow/issues/new?template=bug_report.yml) form. Include the versions it asks for and the smallest test that shows the problem.
- **Ideas**: open an issue with the [Feature request](https://github.com/stevenayers/pytest-databricks-lakeflow/issues/new?template=feature_request.yml) form.
- **Security problems**: see [SECURITY.md](SECURITY.md). Do not open a public issue.

This project is maintained in spare time, so there is no response-time guarantee. Pull requests are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).
